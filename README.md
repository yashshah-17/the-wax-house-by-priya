# The Wax House - by Priya

A responsive, calm, light-themed beauty parlor website built with Astro.

## Run locally

1. Install Node.js 18.20.8+ (Node 20+ recommended).
2. In this folder, install dependencies:
   ```sh
   npm install
   ```
3. Start the dev server:
   ```sh
   npm run dev
   ```
4. Open the local URL printed by Astro (usually `http://localhost:4321`).

## Included

- Editorial-style landing hero and intro
- Responsive navigation with mobile hamburger menu
- Gallery section
- Women's and men's service pricelists
- Contact details
- Responsive layouts and reduced-motion support
